# VOICEVOX版

使用音声：ユーザー提供の18ファイル（番号001〜018）、春日部つむぎ（ノーマル）。
クレジット：VOICEVOX：春日部つむぎ

提供フォルダの音声は変更せず、番号順に場面へ割り当てて使用。
元音声の速度は維持し、各場面で音量を調整して間を設けた。合計60秒。
字幕・映像の尺を音声に合わせて変更。共有の説明を投稿の時系列表示へ差し替え。
ドット絵の描画操作は映像のみ2倍速。ナレーションは倍速にしていない。
従来のmacOS Kyoko版は final/ に保存したまま。
BGMは従来版と同じオリジナル合成音源。
