# floppy.io ヒーローズ・リーグ 提出用動画

## 提出ファイル

- floppy_io_HL2026_60s.mp4：60秒、1920×1080、30fps、H.264 / AAC。字幕焼き込み、日本語合成音声、オリジナルBGM入り。
- floppy_io_thumbnail.png：1920×1080のサムネイル。
- floppy_io_captions.srt：YouTubeなどに追加できる字幕ファイル。
- ナレーション原稿.txt：時刻付きの読み上げ原稿。

## 映像の流れ

0–12秒：コンセプトと1投稿1.44MBの紹介。
12–25秒：ブラウザのドット絵エディタでフロッピーを描く。
25–33秒：短文とAAスタンプ。
33–41秒：添付ファイルを選び、使用バイト数と容量バーの増加を見せる。
41–47秒：コミュニティ「ディスク」。
47–52秒：共有プレビュー。
52–55秒：Nuxt 4 × FastAPI、画面とAPIの容量検証。
55–60秒：作品名、キャッチコピー、公開URL。

## 音声と再編集

ナレーションはmacOSの日本語音声Kyokoを使用。VOICEVOXは使用していない。
BGMは制作スクリプトで合成したオリジナル音源。既存曲の録音は使っていない。
audio/narration_full.wav と audio/original_bgm.wav で個別に音量や差し替えを調整できる。
production/prepare.py と production/render.py に構成と再書き出し処理がある。
字幕SRTは表示用の要約字幕で、ナレーションの逐語起こしではない。

## 確認済みの範囲

最終MP4の全体デコード、60秒の尺、映像・音声の形式、代表フレームでの画面と文字の表示を確認。
音声ピークは約-4.5dBでクリッピングなし。
実アプリの操作収録を使用。投稿公開、YouTubeアップロード、ProtoPedia提出は行っていない。
