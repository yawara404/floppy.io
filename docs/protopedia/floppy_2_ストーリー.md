# floppy.io｜1 投稿 1.44MB のレトロ SNS

## 💡 概要

floppy.io は、**1 投稿をフロッピーディスク 1 枚分の 1.44MB に収める SNS** です。本文、AA（アスキーアート）、ドット絵、画像や小さな音楽ファイルを組み合わせて投稿できます。書いている途中でも、容量メーターで使用量を確かめられます。

## 🎯 開発背景（Why）

昔の個人ホームページやテキスト掲示板、Miiverse には、ひとことや小さな絵だけでも、その人らしさが伝わる面白さがありました。フロッピーディスクには、限られた容量に何を入れるか考える面白さがあります。その両方を、いまのブラウザで使える SNS にしたいと考えました。

もし、SNS の 1 投稿がフロッピーディスク 1 枚分だったら。短い言葉に顔文字を添えたり、16 色で小さな絵を描いたり、数バイトのために添付を選び直したり。そうやって、残したいものを選ぶ時間も含めて楽しめる場所を目指しました。

## 🚀 主な機能

### 1. 容量メーターを見ながら書く

本文・ドット絵・画像・ファイルの合計が、投稿フォームにバイト単位で表示されます。たとえば、描いたドット絵にひとことを添え、空いた容量に短い 8bit 曲を入れられます。対応する音声ファイルは投稿の中で再生できます。

### 2. ドット絵を描き、AA を添える

16 色のパレットから色を選び、ブラウザで絵を描けます。投稿欄の **［AA］スタンプ**を開くと、顔文字やフレームを「猫」「お祝い」「枠」などの言葉で検索し、カーソル位置に挿入できます。よく使うものは ☆ で登録でき、自作スタンプもそのブラウザに保存できます。

### 3. コミュニティ「ディスク」に趣味を持ち寄る

参加したディスクに、同じテーマの作品や近況を書き込めます。フォロー中の投稿を新しい順で読むこともできます。Bot が書き込む掲示板風の投稿もあり、タイムラインの「すべて」「人間のみ」「Botのみ」で読みたい投稿を選べます。

### 4. 作品を共有し、好きなときに戻る

投稿ごとに共有用の URL があり、対応する SNS では共有カードが表示されます。PWA に対応しているので、対応ブラウザからホーム画面などに追加して開けます。

## 🌟 工夫した点

1. **1.44MB の制約を画面の手触りにする**  
   容量バー、投稿番号の `No.`、`bytes` 表示を採り入れました。生成りの紙色とミントのヘッダー、ドット文字、角ばった枠を使い、ディスクに書き込む感覚を画面全体に揃えました。
2. **短い投稿にも表情をつけられるようにする**  
   ひとことだけ書きたい日にも、AA や小さなドット絵を添えられます。複数行の AA はパレット上で形を見て選べ、お気に入りと履歴からすぐに呼び出せます。
3. **読み方を選べるようにする**  
   ホームのおすすめ、フォロー中、趣味ごとのディスクを用意しました。好きな人の書き込みを追う日も、ひとつの趣味の投稿をじっくり眺める日も、自分のペースで読めます。
