# 動画の仕上げ

紹介動画は、実際の操作を収録した 60 秒の VOICEVOX 版です。動画、サムネイル、字幕はそれぞれ既存の素材を使えます。

| 素材 | ファイル |
| :--- | :--- |
| 紹介動画 | [floppy_io_HL2026_VOICEVOX_60s.mp4](../video/hl2026/voicevox/floppy_io_HL2026_VOICEVOX_60s.mp4) |
| サムネイル | [floppy_io_thumbnail.png](../video/hl2026/voicevox/floppy_io_thumbnail.png) |
| 要約字幕 | [floppy_io_VOICEVOX_captions.srt](../video/hl2026/voicevox/floppy_io_VOICEVOX_captions.srt) |

| 時間 | 映像 |
| :--- | :--- |
| 00:00–00:15 | フロッピーディスク 1 枚分の SNS というコンセプト |
| 00:15–00:22 | 16 色のドット絵エディタで描画 |
| 00:22–00:27 | 短い本文に AA スタンプを挿入 |
| 00:27–00:37 | 添付ファイルを選び、投稿の容量メーターを確認 |
| 00:37–00:43 | コミュニティ「ディスク」 |
| 00:43–00:48 | タイムライン |
| 00:48–00:53 | 画面と API の容量チェック |
| 00:53–01:00 | 作品名と公開 URL |

収録後に AA パレットとタイムラインが更新されています。現行画面で撮り直す場合、AA の場面では［AA］を開いて「猫」を検索し、結果を本文に挿入する流れを見せられます。タイムラインの場面で新しい順を紹介するときは「フォロー中」を映します。

音声クレジットは **VOICEVOX：春日部つむぎ**。音量を個別に調整する場合は、[ナレーション単独 WAV](../video/hl2026/voicevox/audio/narration_full.wav) と [BGM 単独 WAV](../video/hl2026/voicevox/audio/original_bgm.wav) を映像の頭に合わせます。場面と読み上げ素材の対応は [VOICEVOX 版の制作メモ](../video/hl2026/voicevox/変更内容.md) と [シーン設定](../video/hl2026/voicevox/production/scenes.json) で確認できます。
